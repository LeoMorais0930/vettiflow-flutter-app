1. O que é a Desmontagem de Produtos?
A Desmontagem de Produtos (MATA242) é a rotina do Protheus que transfere o saldo de estoque de um produto de origem para um ou mais produtos de destino, gerando movimentações internas do tipo RE7 (Recebimento) e DE7 (Devolução). Use sempre que precisar:

Desmontar um produto acabado devolvendo seus componentes ao estoque;
Transferir saldo de 1 produto para outro com quantidades diferentes;
Reprocessar itens sem movimentação para reaproveitar componentes.

2. Onde acessar a rotina
Caminho no menu: Atualizações → Movimentações → Internas → Desmontagem
Ou acesse diretamente pelo SmartLink: MATA242

3. Passo a passo de execução

Carregue os componentes (produtos destino)
Clique em Outras Ações → 1º Nível. O sistema preencherá automaticamente os itens destino com base na estrutura do produto. Se não houver estrutura cadastrada, insira os itens manualmente.
Informe o rateio de custo de cada componente
Para cada linha de produto destino, informe o % de Rateio. Veja a seção 4 para entender como calcular.

Confirme a desmontagem
Clique em Salvar. O sistema irá gerar as movimentações RE7/DE7 e atualizar os saldos de estoque automaticamente.

4. Como calcular o rateio de custo
O campo % Rateio define qual percentual do custo total do produto de origem será transferido para cada componente. A soma de todos os itens deve ser exatamente 100%. O sistema não calcula isso automaticamente — você precisa informar manualmente.

Como consultar o custo médio de cada componente:
No Protheus: acesse 
SIGAEST → Atualizações → Saldos → Atual → pesquise o produto → campo Custo Médio.

Fórmula do rateio:
% Rateio do componente  =  ( Custo Médio do componente × Qtd destino )  ÷  Custo Total do produto origem  ×  100
Onde: Custo Total do produto origem = Custo Médio origem × Qtd desmontada
